# Architecture Decision Records

ChurchCore records meaningful architectural decisions in this directory.

- Use the next four-digit sequential number: `NNNN-short-title.md`.
- Add an ADR before introducing a new system boundary, role-access pattern, integration contract, data-exposure rule, or unusual dependency.
- Record context, decision, consequences, and follow-up work.
- Keep accepted ADRs immutable in intent. Supersede an earlier decision with a new ADR rather than silently rewriting history.
- Reference relevant ADRs from implementation plans, Council syntheses, factory-run notes, and pull requests.
